Cupons Loja Exemplo: economize no seu setup

Vai montar ou atualizar seu computador? Nesta página ficam reunidos todos os cupons ativos da loja. Eles valem para hardware, periféricos, acessórios e outras categorias, e a lista é atualizada sempre que entra uma campanha nova.

Alguns cupons valem para a primeira compra, outros para frete ou para categorias específicas. Vale conferir antes de fechar o pedido.

Como usar um cupom?

  1. Clique no código acima para copiá-lo.
  2. Adicione os produtos ao carrinho.
  3. No carrinho, cole o código no campo “Cupom de desconto” e clique em Aplicar.
  4. O desconto aparece no total antes do pagamento.
